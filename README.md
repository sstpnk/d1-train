# D1 Train

Минимальное Android-приложение для быстрого просмотра ближайших поездов МЦД D1 между Окружной и Белорусским вокзалом.

## Что умеет

- показывает ближайшие поезда по московскому времени;
- разделяет два направления: Окружная -> Белорусский вокзал и Белорусский вокзал -> Окружная;
- открывает список остановок по нажатию на поезд;
- использует Kotlin, стандартные Android Views и `HttpURLConnection`, без тяжелых UI/HTTP-зависимостей.

## Сборка

```powershell
.\gradlew.bat assembleRelease
```

Готовый APK появится здесь:

```text
app/build/outputs/apk/release/app-release.apk
```

Release-сборка минифицируется через R8 и подписывается debug-ключом для личной установки.
