# МЦД

Минимальное Android-приложение для быстрого просмотра ближайших поездов МЦД между выбранными станциями.

## Что умеет

- показывает ближайшие поезда по московскому времени, включая рейсы за последние 3 минуты;
- поддерживает выбор линии D1, D2, D3 или D4 и двух станций;
- разделяет два направления выбранного маршрута;
- обновляется свайпом вниз с резиновым откликом;
- сохраняет выбранную линию и станции в настройках;
- открывает список остановок по нажатию на поезд;
- показывает экран выбора станций при первом запуске;
- использует Kotlin, стандартные Android Views и `HttpURLConnection`, без тяжелых UI/HTTP-зависимостей.

## Установка

Скачай APK из GitHub Releases или собери локально командой ниже.

## Сборка

```powershell
.\gradlew.bat assembleRelease
```

Готовый APK появится здесь:

```text
app/build/outputs/apk/release/app-release.apk
```

Release-сборка минифицируется через R8 и подписывается debug-ключом для личной установки.
